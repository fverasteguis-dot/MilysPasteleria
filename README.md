# 🍰 MILY'S Pastelería

Sitio web responsive desarrollado para una pastelería artesanal especializada en la elaboración de tartas, cupcakes, galletas decoradas, alfajores, 
donas y otros productos personalizados para celebraciones y eventos especiales.

## 🌐 Demo

Puedes visitar la página web en:

https://fverasteguis-dot.github.io/MilysPasteleria/

## ✨ Características

- Diseño responsive adaptado a móviles, tablets y ordenadores.
- Catálogo dinámico de productos gestionado mediante JSON.
- Galería de imágenes por producto.
- Modal interactivo con carrusel de fotografías.
- Formulario de contacto validado mediante JavaScript.
- Integración con EmailJS para el envío de consultas.
- Contacto directo mediante WhatsApp.
- Navegación optimizada para dispositivos móviles.
- Diseño desarrollado con Bootstrap 5.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5
- JSON
- EmailJS
- Git y GitHub
- GitHub Pages

## 📸 Funcionalidades destacadas

### Catálogo dinámico
Los productos se cargan desde un archivo JSON, facilitando la ampliación y mantenimiento del catálogo.

### Galerías de productos
Cada producto puede mostrar una galería personalizada de imágenes mediante un modal Bootstrap y un carrusel interactivo.

### Contacto rápido
Los visitantes pueden:

- Solicitar información mediante formulario.
- Contactar directamente por WhatsApp.
- Enviar consultas por correo electrónico mediante EmailJS.

## 🎂 Objetivo del proyecto

Desarrollar una página web moderna, visual y fácil de mantener para una repostería artesanal, ofreciendo una experiencia atractiva para los 
clientes y facilitando la gestión de los productos y consultas.
